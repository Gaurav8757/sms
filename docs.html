Introduction

ASL SMS provides developers with high-availability REST and SOAP APIs to programmatically integrate transaction alerts, notifications, and DLT approved campaign payloads directly into system workflows.

All API interactions draw from a centralized wallet balance, routing dispatches globally across premium direct carrier gateways with maximum deliverability performance.

Authentication

ASL SMS uses header-based credential validations. Secure your HTTP API requests by injecting authorized credentials in request payloads.

Generate and rotate secure developer credentials inside the API Credentials Manager panel.

Send Campaign SMS

Send single alerts or transactional notifications by dispatching a standard HTTP POST request to the endpoint listed below.

POST https://api.aslsms.com/v1/sms/send
Parameter Type Required Description
client_id string Required Authorized developer client identifier.
client_secret string Required Authorized developer client secret key.
sender_id string Required Approved 6-letter DLT Sender ID.
mobile string Required Recipient number (including country code, e.g. +91).
message string Required DLT approved campaign template payload. 
curl -X POST https://api.aslsms.com/v1/sms/send \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": "client_asl_live_9430184",
    "client_secret": "sk_live_2948194819481048184819",
    "sender_id": "OPNMSG",
    "mobile": "+919876543210",
    "message": "Your login verification OTP code is 8291. Validity is 5 mins."
  }'

Error Codes

ASL SMS uses standard HTTP return codes representing request state outcomes. Inspect payloads and correct validation formatting details when error codes are returned.

HTTP Code Reason Summary Resolution Guideline
200 OK SMS Campaign successfully dispatched. No corrective action needed. Check Sent Logs outbox.
401 Unauthorized Credentials validation invalid or credential rotation in progress. Double-check header configurations and Secret Keys.
403 Forbidden DLT Sender ID or campaign template payload is not approved. Register IDs inside Manage Items panels before routing campaigns.
422 Unprocessable Insufficient account balance to process payload transaction. Top-up your wallet using the "Add Balance (+)" wallet interface.
500 Error Gateway channel timeout. Contact support. Standard retry parameters recommended.
